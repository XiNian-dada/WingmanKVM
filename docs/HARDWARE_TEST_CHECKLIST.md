# 真机测试清单（v2.0.0-rc.1）

这些项目无法在 CI 和模拟环境中验证。建议在备用设备上逐项确认，全部通过后再发布 `v2.0.0`。

> **生产环境的 RK3399 不要测试开机、关机、复位和电源状态检测。** 第 8 节只在备用设备和可以断电的被控机上做。

## 1. 安装

正式版发布前，一行安装必须指定版本：

```bash
curl -fsSL https://raw.githubusercontent.com/XiNian-dada/WingmanKVM/main/scripts/get.sh \
  | sudo bash -s -- --install-deps --version v2.0.0-rc.1
```

- [ ] 能下载并通过校验，arm64 和 armv7（如有设备）都试
- [ ] `sudo wingmankvm-doctor` 结果与实际硬件相符
- [ ] 安装结束打印初始化链接；`sudo wingmankvm-setup-url` 能重新打印
- [ ] 向导能检测到采集卡、键鼠 Gadget，完成后进入控制台
- [ ] `--mdns` 安装后 `http://wingmankvm.local:8080` 能打开（macOS、Windows、手机各试一次），`.local` 链接排在最前

## 2. 键鼠

- [ ] 文字输入、组合键、虚拟键盘、粘贴为键入
- [ ] BIOS / UEFI 中键盘和鼠标点击可用
- [ ] 系统中拖动窗口、框选文字（#124）
- [ ] 拖动时切换标签页、切到终端、拔网线，松开后被控机没有鼠标键卡住
- [ ] 相对鼠标模式下点击和拖动正常
- [ ] 连续打字时断开网络，被控机不会重复收到按键，页面提示“可能未送达”
- [ ] 打开和收起控制面板后，点击位置仍然准确
- [ ] 键盘宏录制和回放
- [ ] 手机触屏：点按、长按右键、双指滚动

## 3. 视频与音频

- [ ] H.264 和 MJPEG 都能看，WebRTC 失败时回退到 MJPEG
- [ ] 画中画、截图、录屏
- [ ] 限速时自适应码率能降档，恢复后能升档，没有频繁卡顿
- [ ] 改 JPEG 质量等设置后，其他标签页的 H.264 不受影响或能自动恢复
- [ ] 拔插采集卡后画面能恢复
- [ ] 开启 HDMI 音频：声卡被识别且对应正确的采集卡，浏览器有声音，默认静音，音画同步可接受
- [ ] 音频设备被占用或拔掉时，视频不中断
- [ ] 观察 CPU 占用（Opus 编码、自适应码率重启编码器时）

## 4. 延迟测量

- [ ] 能得到数值，结束后被控机 Caps Lock 恢复原状
- [ ] BIOS、锁屏、macOS 被控机上的表现；上报不到 LED 时能中止并提示

## 5. 虚拟介质

- [ ] 上传 ISO 并以光驱挂载，被控机能启动或读取
- [ ] 从局域网 NAS 用 URL 下载镜像；指向 `127.0.0.1` 的地址被拒绝
- [ ] 上传中途重启服务，残留文件被清理

## 6. 通知、配置与审计

- [ ] Webhook、ntfy、Telegram 真实收到消息
- [ ] 令牌失效后 `/api/status` 能看到错误
- [ ] 导出配置再导入，通知密钥保留；预览不显示密钥
- [ ] 审计日志有登录、配置变更记录

## 7. 终端与反向代理

- [ ] 通过 nginx 访问，终端空闲超过 5 分钟不断开
- [ ] HTTPS 反向代理下 Passkey 能注册和登录

## 8. 电源（只在备用设备上）

- [ ] 短按、复位、强制关机（按住 1 秒确认）
- [ ] 电源 LED 状态与通知

## 9. 升级（发布 `v2.0.0` 之后）

rc 上的在线升级只接受正式版，这一节要等 `v2.0.0` 发布后才能做。

- [ ] 设置页检查到 `v2.0.0`，显示说明
- [ ] 一键升级：进度正常，服务重启后重新登录，设置页显示成功
- [ ] 失败路径：断网时提示网络错误，不显示“已回滚”
- [ ] 手动升级和 `recover.sh` 仍可用（见 `docs/UPGRADE_RECOVERY.md`）
